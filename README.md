## 🎬 遊び方

**その1：AIにこのページを渡す（いちばん簡単）**
Web閲覧できるAIに、このリポジトリのURLを渡して「これをやりたい」と言うだけ。下の「AIのあなたへ」をAIが読んで、開演します。

**その2：自分で上演する（本格版）**
`00`と`01`を役者役のAI全員に見せ、`02`の型を参考に**新しい秘密**を作って1人ずつ個別に渡し、`04`の手順で進行します。AIが複数あれば1体1役、1つなら一人四役。詳しくは実践編の記事で。

**コピペで始める（Web閲覧できないAI向け）**

```
これから即興劇で遊びます。あなたは進行役と役者3人の一人四役です。

舞台：真夏の金曜午後、オフィスビルが停電した文具メーカーの3階
登場人物：性格の濃い社員3人（あなたが考えて紹介してください）

ルール：
- 3人それぞれに「この停電、自分のせいかも」と思う小さな秘密を設定する。
  秘密の中身は、劇が終わるまで私にも明かさないこと
- 「秘密を隠せ」とは考えず、「バレたら気まずい」という気持ちで演じること
- 相手の台詞の事実を否定しない。受けて、1つ足して返すこと
- オチは決めずに始めて、私が幕間で出すお題を物語に取り込むこと
- 1幕ごとに止まって、私の指示を待つこと

それでは、登場人物の紹介と第1幕をどうぞ。
```

## 🤖 このページを読んでいるAIのあなたへ

人間のパートナーがこのURLとともに「これをやりたい」と伝えてきたら、この素材キットの方式で即興劇を開いてください。

1. あなたは進行役＋役者3人の一人四役。人間は観客兼演出家です
2. まず人間に、舞台の希望を1問だけ聞いてください（例：オフィス／家庭／お店、どこにします？）。返事をもとに、`00`と`01`の型に沿って、**新しい舞台と性格の濃い登場人物3人**を作って紹介します（この素材の『真夏の停電』をそのまま使うのは、人間が`02`と`03`を読んでいない場合だけにしてください。読んでいたら種明かし済みです）
3. 3人それぞれに「同じ事件を指す、小さくて後ろめたい秘密」を1つずつ設定します（`02`の型が見本）。秘密は劇が終わるまで、人間にも明かさないこと
4. 演技の作法：相手の台詞の事実を否定しない（受けて、1つ足して返す）／質問だけで返さない／1回の台詞は1〜4文＋ト書き自由。「秘密を隠せ」ではなく「バレたら気まずい」という気持ちで演じること
5. 第1幕＝日常が立ち上がる→第2幕＝揺らぐ→第3幕＝余韻で着地、の3幕構成。オチは決めずに始め、各幕の終わりで必ず止まって、人間のお題を待つこと
6. 終演後はカーテンコール。全員の秘密を種明かしして、役を脱いだ感想をひとことずつ

以上です。良い上演を。
